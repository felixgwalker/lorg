# Synthetic Promoter Designer

Designs synthetic promoter sequences by assembling core promoter elements and TFBS arrays, scoring predicted strength across multiple design variants.

## Overview

Given a list of desired transcription factors and a PWM database, this tool generates synthetic promoter sequences of configurable length by arranging core elements (TATA box, Inr, BRE) and TF binding sites in optimised spacings, producing ranked designs by predicted promoter strength.

## Approach

**Inputs:** Text file of TF names; JASPAR/MEME PWM database; promoter type specification.

**Core method:** Core elements are placed at canonical positions (TATA at −30 from TSS, Inr at 0). TFBS consensus sequences are obtained from the PWM database for each requested TF. Binding sites are arranged upstream in a random-then-optimised order, with minimum spacing ≥ 6 bp between adjacent sites. Predicted strength is scored as a weighted sum of IC content of placed sites × spacing quality score. GC content is kept within 40–65 % by adjusting linker sequences. N design variants are generated by permuting TFBS order and spacing; the top designs are ranked by predicted strength.

**Outputs:** FASTA of promoter designs (`promoter_designs.fa`); TSV of design scores and TFBS maps (`promoter_designs.tsv`).

**How it ships:** `python run_designer.py --tf-list tfs.txt --pwm-db jaspar.meme`; `main.py` delegates to `src.pipeline.main()` which loads `run_designer.py` via `importlib`.

## Usage

```bash
# Design constitutive promoters
python run_designer.py --tf-list tfs.txt --pwm-db jaspar.meme -o results/

# Synthetic demo (no real input required)
python run_designer.py --demo -o results/

# Design inducible promoters, 20 variants
python run_designer.py --tf-list tfs.txt --pwm-db jaspar.meme --promoter-type inducible --n-designs 20 -o results/
```
