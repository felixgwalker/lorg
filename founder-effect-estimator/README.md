# Founder Effect Estimator

Estimates the strength and timing of a founder effect by comparing nucleotide diversity, private variant fraction, and haplotype block length between study and reference populations.

## Overview

Given VCFs for a study (potentially founded) population and an ancestral reference, this tool computes diversity statistics for both, calculates the diversity ratio and private variant fraction, and classifies the founder signature as strong, moderate, weak, or absent. Optional inference of founder population size and time since founding is provided.

## Approach

**Inputs:** VCF of study population SNPs; VCF of ancestral/reference population SNPs.

**Core method:** Watterson's θW, θπ, and Tajima's D are computed per population. The diversity ratio (θW_study / θW_ref) measures the reduction in diversity; values < 0.5 suggest a strong founder effect. The private variant fraction (proportion of variants unique to each population) and mean haplotype block length (long blocks indicate recent bottleneck) are additional signatures. Founder population size is estimated by modelling the expected reduction in diversity as a function of Ne and the number of generations since founding, solved numerically. Bootstrap confidence intervals are generated by resampling genomic windows.

**Outputs:** TSV of diversity statistics per population (`diversity_stats.tsv`); founder effect summary (`founder_effect_summary.tsv`); optional plot of diversity ratio distribution.

**How it ships:** `python run_estimator.py --study-vcf study.vcf --reference-vcf ref.vcf`; `main.py` delegates to `src.pipeline.main()` which loads `run_estimator.py` via `importlib`.

## Usage

```bash
# Estimate founder effect comparing two populations
python run_estimator.py --study-vcf island.vcf --reference-vcf mainland.vcf -o results/

# Synthetic demo (no real input required)
python run_estimator.py --demo -o results/
```
