# Demographic History Inferencer

Infers demographic history by fitting parametric models to the site frequency spectrum and selecting the best model by AIC.

## Overview

Given a single-population VCF, this tool constructs the observed folded SFS, fits a set of demographic models (constant Ne, exponential growth, two-epoch, three-epoch), computes log-likelihoods via diffusion approximation or moments-based inference, and selects the best-fit model. Bootstrap confidence intervals are generated for all parameters.

## Approach

**Inputs:** VCF of bi-allelic SNPs from a single population.

**Core method:** The folded SFS is computed from allele count data. Each demographic model is parameterised and its expected SFS is predicted via the diffusion approximation to the Wright-Fisher model (or discrete-time moments for speed). Parameters are optimised by maximising the multinomial likelihood of the observed vs. expected SFS using L-BFGS-B, repeated from multiple random starts to avoid local optima. AIC (= 2k − 2 ln L) is used for model selection. Bootstrap CIs are generated by parametric resampling from the best-fit expected SFS.

**Outputs:** TSV of model fits and AIC values (`demographic_model_fits.tsv`); parameter table for best model; optional Ne trajectory plot.

**How it ships:** `python run_inferencer.py variants.vcf`; `main.py` delegates to `src.pipeline.main()` which loads `run_inferencer.py` via `importlib`.

## Usage

```bash
# Infer demographic history from a real VCF
python run_inferencer.py variants.vcf -o results/

# Synthetic demo (no real input required)
python run_inferencer.py --demo -o results/

# Fit only two-epoch and three-epoch models
python run_inferencer.py variants.vcf --models two_epoch three_epoch -o results/
```
