# Bottleneck Detector

Detects historical population bottleneck signatures using multiple complementary tests calibrated against coalescent simulations.

## Overview

Given a single-population VCF, this tool applies Tajima's D, the heterozygosity excess Wilcoxon (HEW) test, SFS mode-shift detection, and the M-ratio to identify whether the allele frequency spectrum and haplotype structure are consistent with a recent population bottleneck. Results from each test are combined into a composite signal classification.

## Approach

**Inputs:** VCF of bi-allelic SNPs from a single population.

**Core method:** (1) **Tajima's D** — negative values indicate an excess of singletons (expansion or purifying selection); strongly negative under recent bottlenecks with recovery. (2) **HEW test** — compares observed heterozygosity to mutation-drift equilibrium expectation across loci. (3) **SFS mode shift** — a shift of the mode from singletons to intermediate frequencies is a classic bottleneck signature. (4) **M-ratio** — the ratio of allele count range to number of distinct alleles; low values indicate reduced allele number under drift. A null distribution for each test is generated by coalescent simulation under a constant-size neutral model. A combined signal is reported as strong, moderate, weak, or none.

**Outputs:** TSV of per-test statistics and p-values (`bottleneck_tests.tsv`); optional SFS plot.

**How it ships:** `python run_detector.py variants.vcf`; `main.py` delegates to `src.pipeline.main()` which loads `run_detector.py` via `importlib`.

## Usage

```bash
# Run all bottleneck tests
python run_detector.py variants.vcf -o results/

# Synthetic demo (no real input required)
python run_detector.py --demo -o results/

# Run only Tajima's D and M-ratio
python run_detector.py variants.vcf --tests tajimas_d m_ratio -o results/
```
